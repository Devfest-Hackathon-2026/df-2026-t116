# 0007 案Dの採用（案Aからの切替）

- 状態: 決定
- 日付: 2026-11-10（前提メモ追記 04:15 JST。設計書 PR #19 は 04:33 JST に main へマージ）
- 決定者: Haruki さん。案D のアイデアシートは 11/9 に中村さん＋AI が下書き（PR #17）、設計書は AI が下書きし Sol（別のAI）と Opus が点検
- 関連: PR #17・#19、#18、[0002](0002-tech-stack.md)、[0008](0008-serial-format.md)、[0009](0009-human-story-ai-art.md)

## 背景

- 参加の目的は優勝・決勝進出（2026-11-07 22:55 Haruki さん）。案の条件: (1) AI アプリ単体でできることはプロダクトにしない (2) 使うときに問題解決まで踏む手順が少ないこと（2026-11-07 23:21・23:24）。
- 11/8〜11/9 は案A（授業中の「分からない」をその場で返す）で詰めていた:
  - 授業中に分からなくなった学生がタップすると、今のスライドと次の数枚から「この先を追うのに最低限必要なこと」を返す。つまずきの種類ごとにボタンを分け、判定は Gemini の構造化出力（2026-11-08 00:00）。
  - 対象はスライドが学生に配布される授業。Web アプリで、教授が毎回資料をアップロードし、学生はアプリ上で閲覧する。文系も含む。デモ題材は未決（2026-11-09 08:46〜08:53）。
- 11/9 に中村さん＋AI が案D（お題に続きを付け合う4コマ）のアイデアシートを書いた。課題設定は「話を考えるのは好きだが絵が描けない人が、思いついた話を漫画で読んでもらえない」「AI が中身まで作ると人の作品として見てもらえない」。
- 締切はコード 11/10 18:00 JST・凍結 19:00 JST。カテゴリは5つ（医療・福祉／観光／教育／エンタメ／クリエイティブ）から選択必須で、外れると審査対象外。

## 検討した選択肢

### 案A: 授業中の「分からない」をその場で返す（教育）
- 利点: 社会課題が明確。リアルタイム性という価値がはっきりしている（Haruki さん 11/7）。
- 欠点: 教授が資料をアップロードし学生が閲覧する仕組みと、ページごとのボタン判定が要る。デモ題材が未決だった。切替の判断材料としての欠点は記録に無い（未確認）。

### 案D: お題（物語の軸）に続きを付け合い、AI が漫画にする（エンタメ／クリエイティブ）
- 利点: 「話は人、絵はAI」で、AI アプリ単体では作れない「みんなで続きを作る場」になる（条件1）。1行書けば漫画になり手順が少ない（条件2）。デモで「書く→漫画になる→投票で本筋が変わる」を見せやすい。
- 欠点: 画像生成の費用と待ち時間がかかる（[0006](0006-generation-cost.md)・[0012](0012-generation-limits.md)）。著作権への配慮が要る（[0005](0005-start-flow.md)）。

## 決定

- **案Aではなく案D**（お題＝物語の軸に続きを付け合う漫画）で実装する。設計は [design-d-4koma.md](../design-d-4koma.md)（のちに連載形式 [0008](0008-serial-format.md) と開始フロー [0005](0005-start-flow.md) で更新）。
- AI は Vertex AI＋実行サービスアカウント（ADC・API キーなし）。spend cap はデプロイ／初回呼び出しの前に docs/11 どおり。打ち切りは `/api/nodes` 120秒（同じ決定の中で確定。[0002](0002-tech-stack.md)・[0010](0010-gcp-billing-guards.md)・[0012](0012-generation-limits.md)）。
- カテゴリはエンタメ／クリエイティブ寄り。提出フォームでの選択は人の作業で、2026-11-10 10:00 JST 時点では未決（#31 の未完了項目）。

## 理由（判断基準）

- Haruki さんが切り替えた直接の理由の言葉は、前提メモにも PR にも記録が無い（**未確認**）。この ADR の旧版には「当日の実装・デモ規模と合わなくなった」と書いていたが、出典は確認できていない。
- 記録から読み取れる判断材料:
  1. 案D のアイデアシートと設計書が 11/9〜11/10 にそろい、締切内に作る範囲（1本道）が決まっていた。
  2. 案の条件（AI 単体でできない・手順が少ない）を満たす。
  3. デモで通す1本道が短い（設計書 1節）。
